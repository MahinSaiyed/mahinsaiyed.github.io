# 🌐 Mahin Saiyed – Personal Demo Website

This repository contains my personal demo website, built to showcase simple, clean, and practical web design for local businesses and small shops.

The website focuses on clarity and usability rather than complex features, making it suitable for business owners who want customers to easily find them online and contact them directly.

## 🚀 Live Demo
🔗 https://mahinsaiyed.github.io

## 🎯 Purpose of This Project
- Personal demo / portfolio website  
- Showcase simple, sales-focused website layout  
- Demonstrate mobile-friendly and clean design  
- Example website for local shops and small businesses  

## 🛠️ Technologies Used
- HTML5  
- CSS3  
- JavaScript  

(No frameworks used – intentionally kept simple)

## ✨ Features
- Clean and minimal UI  
- Mobile responsive layout  
- Fast loading static website  
- Easy-to-understand structure  
- Suitable for local business websites  

## 📌 Use Case
This project can be used as:
- A personal portfolio website  
- A demo website for local shops  
- A reference layout for small business websites
